PASOS COMPLETOS

1. Clonar repositorio

```md
```bash
git clone <URL_DEL_REPO>
```

---

2. Abrir proyecto en IntelliJ

- Abrir IntelliJ
- Click en "Open"
- Seleccionar la carpeta del proyecto

---

3. Configurar JDK

- Ir a: File → Project Structure
- Seleccionar JDK 11 o 17

---

4. Cargar dependencias

- Ir a panel Maven
- Click en "Reload Project"

---

5. Ejecutar pruebas

- Ir a archivo `CarritoServiceTest`
- Click derecho → Run
